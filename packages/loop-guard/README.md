# dsh-plugin-loop-guard

**思维链循环守卫**：检测 agent 的推理块陷入原地打转（同一批短语反复几百次、不出正文不调工具），
检出后**截断本轮流**（默认 `cut`），避免白烧 token。

## 判据（三条，全部带标定）

| 判据 | 逻辑 | 来源 |
|---|---|---|
| 周期 | 滑动窗口 zstd 压缩比（重复文本压缩率异常高） | 参考项目思路 + 本机标定 |
| `reasoning-flat` | 窗口内字符唯一率 < 0.30（字符级坍缩） | 本机真值集标定 |
| `reasoning-stub` | 最近 20 行里「含语言字符的短行（≤4 字）」占比 ≥ 30% | 本机真值集标定 |

**两条护栏**（都踩过坑）：

- `reasoning-flat`：窗口内有代码围栏 ⇒ 整窗跳过（否则误伤 edit 的 old/new 代码对比）
- `reasoning-stub`：只认**含语言字符**的短行（否则源码里的 `}` / `);` 被算成碎片）

## 模式

| 模式 | 行为 |
|---|---|
| `cut`（默认） | 截断本轮流（实测：往流里注入提示拦不住生成中的那一步）|
| `inject` | 向推理流注入收尾提示 |
| `break` | 中断 |

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `LOOP_GUARD_LOG` | `~/.dsh/logs/loop-guard.log` | 日志路径（测试用独立文件，避免污染生产日志）|

## 注意

- 判据是**启发式**的：可能误伤（长推理 / 大量重复代码）；默认 cut 只截断不报错
- 阈值标定依赖真实循环样本，换模型/换任务分布后建议重新标定
- DSH **0.2.2-rc.1+** · 零运行时依赖 · host-only
